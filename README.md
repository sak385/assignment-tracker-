# Assignment Tracker - Personal Project 
A simple personal assignment tracker I built because I wanted a better way to keep track of my coursework, deadlines, and completed assignments.  The goal was to create a lightweight tool that makes it easier to see what is coming up, organize assignments, and add a little personalization with color-coding.

## Features
- Add assignments: Enter an assignment name and due date.
- Sort by due date: Assignments are automatically displayed in order of their upcoming deadlines.
- Track progress: Check off assignments when they are complete. The tracker separates incomplete and completed assignments into two sections.
- See deadline reminders: Each assignment displays how many days remain until it is due, whether it is due today, or how many days overdue it is.
- Edit or delete assignments: Update an assignment's name or due date, or remove it from the list.
- Customize assignment colors: Choose a highlight color for each assignment.
- Save favorite colors: Give colors names, reuse them for future assignments, and delete saved colors when they are no longer needed.
- Keep your data: Assignments and saved colors are stored in the browser using local Storage, so they remain available when you close and reopen the page in the same browser.

## Languages and Tools
JavaScript, HTML, CSS, PowerShell, VS Code

## Repository Structure
Each assignment has its own folder to keep the source code organized and separate.
